# 网球日记隐私保护指引

更新日期：2026-06-21
生效日期：2026-06-21

网球日记是一款用于记录个人网球活动、球拍装备和穿线信息的微信小程序。我们重视你的个人信息和隐私保护，并会尽量只收集实现产品功能所必需的信息。

## 一、我们收集的信息

为提供登录、记录、同步和展示功能，我们可能收集以下信息：

1. 微信登录标识
   - 通过微信小程序登录能力获取登录凭证，并由后端换取用户身份标识。
   - 用于识别账号、保存和同步你的网球记录。

2. 用户资料
   - 昵称
   - 头像
   - 以上信息仅用于小程序内个人资料展示。

3. 网球记录信息
   - 打球日期
   - 打球时长
   - 打球类型
   - 场地
   - 搭档
   - 球拍
   - 球鞋
   - 花费
   - 手感评分
   - 比赛成绩

4. 装备信息
   - 球拍名称、品牌、型号、状态
   - 购入日期、价格
   - 穿线记录、磅数、费用

## 二、我们如何使用这些信息

我们会将以上信息用于：

- 保存和展示你的打球记录
- 统计月度、年度打球情况
- 管理球拍和穿线记录
- 多设备登录后同步你的个人数据
- 优化产品体验和排查问题

我们不会将你的个人网球记录公开展示给其他用户。

## 三、信息存储

你的记录数据会保存到我们的后端服务中，用于跨设备同步和长期查看。

在当前阶段，记录数据以 Go 后端 API 为准；服务端不可用时，小程序不会静默写入本地缓存作为替代。

## 四、信息共享

除以下情况外，我们不会向第三方共享你的个人信息：

- 获得你的明确同意
- 法律法规要求
- 为维护服务安全或排查故障所必需

## 五、你如何管理信息

你可以在小程序内：

- 新增、编辑、删除打球记录
- 新增、编辑、删除球拍信息
- 修改头像和昵称
- 退出登录

如需删除账号或清理全部数据，可通过开发者联系方式提出请求。

## 六、未成年人保护

如果你是未成年人，请在监护人同意和指导下使用本小程序。

## 七、联系我们

如果你对隐私保护有疑问，可以通过小程序内反馈渠道或开发者联系方式与我们联系。

## 八、变更

本隐私保护指引可能会根据产品功能变化进行更新。更新后会在小程序中提示或展示最新版本。
